# Qaroshi Unified Standard 8.0 · Release notes

- Consolidated current grammar of **90 numbered chapters** with **14 in-chapter normative rulings** and corrected obsolete instructions, preserving the frozen 7.0 source.
- Current **30,001-entry** dictionary, base and enriched forms (original 30,000 entries unchanged plus post-7.0 `nëgëra`). Enriched lexicon includes reviewed sense notes, lexical boundary comparisons, source references, verb license status and compound cautions.
- All **400 indexed verbs** receive a specific, traceable decision. The prior **25** remain fully reviewed general-purpose frames. **244** more verbs have an exact source-licensed object pattern; **131** have a restricted recorded finite construction; no generalized voice/argument behavior is falsely invented.
- **52 lexical decisions**, comprising **40** individual constrained senses of existing compounds and **12** preserved rejected replacement proposals. A sorted **3,108-entry risk register** allows future focused review without mass-renaming any canonical form.
- A new, **restricted** two-quantifier scope convention with case-independent linear scope, **24 contrastive examples**, **16 binary relation models**, and strict abstention when a clause exceeds the supported grammar.
- **265** blind comprehension prompts, answer key kept in a separate file, opt-in anonymous scorer, evidence policy and clear limitation that no independent participants were tested.
- One current README and a migration guide. No website or unrelated feature churn.
- Legacy 7.0 corpus, 24–34 amendments and **29 historical source SHA-256 records** unchanged.

The verb and compound inventories preserve distinction between fully generalized norm-setting, exact editorial examples and unresolved semantic claims. Formal machine checks and an unadministered test instrument do not make the language empirically validated or guarantee every possible sentence is natural.
