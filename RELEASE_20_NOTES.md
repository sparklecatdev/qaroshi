# Qaroshi 20.0 Release Notes

The practical language release now includes a standalone **Spoken Language Studio** with a real offline recording interface, phoneme articulation cards, lexical minimal-contrast pairs, citation stress exercises, an abstract metrical-rhythm generator (not a voice), a 14-day speaking course, and a 3,000-item source-verified recording queue.

Recording, waveform, playback, technical loudness estimation, explicit local-capture consent, download and session metadata are implemented in the browser. There is **no network upload** and no native voice model. This does not fabricate or substitute for speaker-verified audio, tested dialect variations, or certified pronunciation.

All 26 canonical glyph/sound values, 30,000 lexemes, 4,383 source sentences, 16 resonance markers and original grammar references remain unchanged. The GitHub integration consists only of new `v20` source, data, documentation and tests. The standalone HTML can be rebuilt from the included generator and may be shipped compressed in GitHub when a repository gateway has a per-file size limit.
