# Qaroshi 21.0 + 22.0 + 23.0 release notes

## Why this release exists

The 30,000-word standard, 4,383 controlled bilingual pairs and growing original editorial corpus had become hard to navigate as usable language. The previous practical releases improved chat, word analysis and phonetics. This release adds a conservative source-backed **bilingual discovery tool**, a connected **immersion reader**, and **assessment/semantic review workflows**.

## New components

- **21.0 Translation & Meaning:** exact lookup among 5,249 contextual source pairs; source alternatives, pronunciation, word links, a 103-case editorial discrepancy ledger and explicit abstention when no source match exists. The standalone Python CLI uses the inherited conservative v11 morphosyntax analyzer to interpret or generate within *limited* validated patterns, with uncertainty labeled.
- **22.0 Immersion:** 108 archived editorial readings with 866 source lines, graded by a relative difficulty proxy, individually revealable contextual English, dictionary deep links, source references, and thematic filters.
- **23.0 Learning:** 324 deterministic original-line matching questions, 12 practical learning steps, progress export/import, and locally editable personal reviews of unresolved meaning issues.

## Grounding and invariants

- **No canonical word, inflection, resonance marker, glyph, grammar or reference sentence changed**. The preserved base contains the official 30,000-word lexicon, 4,383 reference examples, 90 grammar chapters, 16 written resonance markers, and 26 glyph artworks.
- **No independent fluent speakers, real learner grades, empirical reading levels or speaker recordings were invented**. The corpus remains editorial and controlled rather than human-spontaneous.
- Related search matches are **not translations**. Editorial alternatives in the QA ledger remain **unapproved**. Test scores are source-matching recognition, not a certified fluency measurement.
- No network API, login or analytics in the offline application. Review notes remain local until explicitly exported.

## Acceptance and validation gates

- 29 baseline source file SHA256 checks must match exactly.
- All 5,249 indexed references match their original archive lines and source IDs.
- All 324 quiz options have exactly one explicit documented target and 3 distinct distractors.
- A previously unlicensed English construction must trigger an explicit no-translation result.
- End-to-end browser checks exercise lookup, abstention, immersion reveals, reader-to-word links, question scoring, private review notes, and mobile layout.

## Future research direction

The next stages should focus on **24: independent learner and speaker review**, **25: consented speech evaluation**, and **26: generalized translation only after meaning and grammar are independently tested**. No unobserved participant data should be claimed before that research actually happens.
