# Standard 8.1 · Linguistic Stress-Test Triage

This report is grounded in the 500 English challenges generated by `tools/stress81/scenarios.py`, the current Standard 8.0 grammar and the 28–34 source-linked language amendment. **A translator's inability to produce a sentence is not proof the language lacks that grammatical construction.** No natural-language speaker ratings were collected.

**Interpretation:** The current tool is a conservative lookup/construction assistant, *not* a general language translator. Its 100% abstention on this deliberately adversarial suite is a valid diagnostic of **tool generalization**, not a failed proof of all 500 concepts' grammatical expressibility. The 49 independently generated draft constructions have dictionary/POS and rule witnesses, but not external semantic validation.

## What was fixed now

**Issue G8.1-A: underspecified complement-question boundary.** The inherited chapter 73 distinguishes direct and embedded questions but explicitly asks writers to break up ambiguous double-`he` forms. Standard 8.1 establishes a precise boundary: embedded `he` occurs immediately before `do`, matrix `he` after the matrix predicate. Predicate negation is local to each clause. A restricted recognizer and negative tests check these distinctions. The original dictionary and 29 checksum-protected sources are unchanged.

**Issue G8.1-B: confounding "not every" with "none" in generation.** This had already been fixed normatively by `nëgëra` in 28–34. The new challenge suite explicitly tests the contrast against `ngënao ... nu ...` for ten separate documented noun+adjective pairs, and constructs 49 source-grounded outputs. No redundant new particle was invented.

## Release gate before declaring general functionality

A future release may claim improved **coverage** only with item-level Qaroshi versions, independent back-translations and explicit source or reviewer evidence. For each target feature, preserve counterexamples and prove that alternatives with different truth conditions remain distinct. Automated unit tests protect the specification; they are not substitutes for people understanding it.

No current data justify claiming all 500 unfamiliar English sentences were translated into correct, idiomatic Qaroshi. Instead, this stress audit honestly identifies the work that remains, alongside one real small grammar amendment and 49 bounded editorial constructions.
