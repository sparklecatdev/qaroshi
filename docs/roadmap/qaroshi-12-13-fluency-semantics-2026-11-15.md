# Qaroshi 12.0–13.0 editorial fluency & meaning checkpoint

**Date:** 2026-11-15
**Status:** Separate, tested local development archive; **not** a ratified standard, speaker corpus or fully uploaded GitHub source release.

## Baseline preservation

The complete local archive preserves, unchanged and SHA-256-checked against the prior 11.0 package:
- **30,000** dictionary entries and identifiers
- **4,383** bilingual controlled reference examples
- **90** grammar chapters
- **26** original Nardoragon native glyph PNGs
- **16** mandatory written sentence-opening resonance markers

## 12.0 independent editorial writing

- **54** new separately scripted editorial conversations, **434** turns, **1,866** Qaroshi source tokens
- With the preceding 49 scenes, **103** different editorial situations are browsable
- **18** new stories and essays, **255** sentences, **1,069** Qaroshi source tokens
- Across 689 new sentences, 437 distinct Qaroshi strings; conservative construction leads to some repeated formulae
- Genres include travel diary, fictional report, ethics essay, epistolary fiction, literary story, arts discussion and language-learning essay
- **103** source/translation alignment risk flags remain for human inspection; parser issues alone do not prove a wrong translation

The material is independently *drafted* editorial writing, not transcribed spontaneous conversations and not the full naturalistic 100,000-word corpus goal.

## 13.0 semantic precision

- **61** individual core-word distinction profiles, with usage restrictions, contrasts and contextual examples
- **40** individually written figurative interpretation proposals, each with literal meaning, context and counterexample. **0 are claimed speaker-attested or conventionalized.**
- All **1,000** earlier idiom candidates audited; **454** received heuristic semantic/collocational caution flags
- All **5,000** earlier sense cards audited; **4,791** require contextual or valency example review. This does **not** mean 4,791 dictionary definitions are wrong.
- **16** resonance-in-context situations; the original written markers remain stable.

## Interactive deliverables and tests

The local archive contains an offline Qaroshi 12+13 Language Studio with 103 conversations, anthology, core meanings, metaphor study, resonance guide, editable 6,000-item quality-review queue, grammar-contrast exercises and dictionary lookup. The existing Wiki, Academy, 11.0 translator and other tools are retained.

- **267 Python unit tests passed**, including new release tests
- **26 desktop/mobile Chromium UI checks passed** with zero page errors
- The 373-file ZIP passed its integrity test, then passed **267 tests on fresh extraction** (one compiled-font-specific test skipped because the archive correctly omits font binaries)
- The original 26 glyph images and canonical source records remain unchanged.
