# Qaroshi Standards 8–10: editorial completion workbench (2026-11-15)

This branch accompanies the existing draft language roadmap and is **not** a claim that every original checklist target has been satisfied.

## Local source release candidate

A downloadable 276-file source archive was prepared in the ChatGPT conversation, preserving all **30,000** canonical dictionary entries, **90** grammar chapters, **16** required written resonance markers, and **26** native handwritten glyphs. The complete ZIP has **not** yet been pushed to GitHub.

### Audited editorial materials
- 1,000 proposed idiom expressions, automatically checked for spelling/morphology against the lexicon. **0** independently speaker-attested or culturally approved as fixed idioms.
- 5,000 source-linked word-sense cards, mechanically checked for source spelling/gloss/POS. **0** independently accepted as distinct senses by this audit.
- 12 separately drafted, structurally checked dialogue scenes / 96 turns.
- 5 new short, IPA-annotated editorial readings / 50 sentences.
- Earlier 1,000 dialogues and 123,000 source tokens remain controlled pedagogical variations rather than 1,000 independent natural conversations or a naturalistic general corpus.
- Improved limited grammar analyzer and an explicit 15-pattern English→Qaroshi translator, both of which decline unsupported full-sentence translations.
- A standalone offline Completion Workbench with 94 meaning-contrast exercises, searchable dictionary, idiom/sense review decisions, native glyph visualizer, and a consent-first microphone capture helper.
- 3,000 audio collection targets; **zero human recordings**. No real dialect field evidence has been collected.

### Verification
- 214 Python tests passed after a local build of the 26-glyph experimental font.
- Source ZIP integrity verified. Native font builder and glyph art are included, but compiled font binaries are not distributed in the shared archive.
- JavaScript syntax was checked with Node. Interactive browser testing was **not** completed because local navigation was blocked by the managed Chromium URL policy in that environment.

## Still requiring independent completion

Speaker/community review of idioms and meanings; 1,000 genuinely independent conversations; diverse 100,000-word literary/conversational corpus; consensual pronunciation recordings and any empirically supported dialect claims; actual keyboard installer/device tests; general-purpose bilingual translation and semantic grammar checking; mastery benchmarking; full GitHub source publication and editorial approval.

This remains a **draft** and should not be merged as an approved all-tasks-complete language standard. See issue #1 and PR #2 for the audit and contributor workflow.
