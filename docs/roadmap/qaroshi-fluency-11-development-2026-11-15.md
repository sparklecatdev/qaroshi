# Qaroshi 11.0: Fluent Conversation & Translation Development

**Status:** Editorial development release. The complete, independently verified local source ZIP was generated through the ChatGPT conversation; it has **not** been pushed as a full GitHub release or merged. This document is a release checkpoint, not the complete source distribution.

## Achievements

- Canonical 30,000 lexicon entries, 4,383 reference examples, 90 grammar chapters, 26 original native letters and 16 mandatory sentence-initial written resonance markers preserved without changes.
- A more capable but intentionally **bounded** Python translator, including recognized noun-case and verb inflection slots, SOV arguments, polarity, question marker `he`, modal distinctions `-ki/-ho/-du`, and exact matches to existing bilingual reference examples. Unsupported expressions are left unresolved rather than fabricated.
- A machine-checked table of **1,572 productive English/Qaroshi sentence pairs**, excluding obvious coreferential object errors. This is not unrestricted translation.
- **49 individually scripted editorial dialogue scenes**, **294 annotated turns**, and **1,263 source-language tokens**. Each provides contextual English, a separate literal/reference reading, IPA and sound-out. They are not spontaneous human-authored recorded conversations or a complete 1,000-conversation corpus.
- A **472-question self-study bank** across five internal levels Q1–Q5, including 26 native-glyph prompts, resonance, morphology, meaning contrasts, translation and contextual reading.
- A standalone offline, responsive HTML learning app containing translation lookup, sentence builder, original dialogue reader, five reading pieces, 30,000-entry dictionary, 26 display glyphs, five-level practice assessment, and local progress export/import.
- **249 Python tests passed and 46 Chromium desktop/mobile checks passed with no page errors.**
- A quality ledger records contextual paraphrases separately from grammar-engine interpretations and explicitly flags 10 priority review cases. It is a *review queue*, not an independent verification.

## Not completed

- An unrestricted or independently validated Qaroshi MT model.
- 1,000 distinct spontaneous conversation recordings or a naturalistic 100,000-word corpus. Prior 123,000 tokens remain predominantly templated pedagogical dialogue.
- Culturally accepted idioms, field-observed dialects, authentic licensed human pronunciations.
- External proficiency accreditation, native mobile installer certification, rights-cleared font licensing, or publication of the full 11.0 ZIP to GitHub.

## Review principle

The original 26 letters and 16 mandatory typed resonance markers remain stable. An editorial text is not an empirical linguistic record; computational structural checks do not certify naturalness.

Issue #1 and PR #2 track the broader unfinished language roadmap. Please keep this work in draft until real-language editorial review and complete source publication are performed.
