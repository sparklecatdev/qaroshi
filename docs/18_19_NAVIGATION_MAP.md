# Living Language Studio navigation map

| Start | Click/follow | Destination |
|---|---|---|
| Top search | Word, English gloss, scene, phrase, rule, proposal or study path | Deep link to exact resource |
| Conversation | Highlighted Qaroshi word | Canonical dictionary entry |
| Conversation | Source ID (e.g. `S00001`) | Full bilingual phrase record |
| Phrase | Highlighted Qaroshi word | Dictionary entry |
| Phrase | Related scene / related phrase | Conversation / phrase |
| Dictionary | Documented modifier/head of compound | Canonical component dictionary entries |
| Dictionary | Existing compound using component | Canonical compound dictionary entry |
| Dictionary | Nearby gloss | Dictionary entry (not necessarily an exact synonym) |
| Dictionary | Source example | Phrase record |
| Dictionary | Candidate root-reform proposal | Separate, unapproved proposal review |
| Grammar | Highlighted Qaroshi words | Canonical dictionary entry |
| Practice | Revealed phrase words | Canonical dictionary entry |

All routes are URL hash fragments, work with offline `file://` pages and support bookmarks. Keyboard global search is Ctrl/Cmd+K or `/` when outside text fields. The design uses safe text nodes for lexicon data and never interprets user-supplied dictionary strings as HTML. Mobile tabs display in two rows with no hidden overflow.
