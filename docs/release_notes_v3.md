# Qaroshi Standard Reference 3.0: Expansion Draft

## Compatibility

- Preserves **all 6,819 Reference 2.0 headword rows**, including stable IDs, spelling, POS, English gloss, origin and status.
- Preserves **all 880 Reference 2.0 parallel-sentence rows**, including previously existing duplicate-example sentences; no old row is deleted or rewritten.
- Retains all 26 handwritten native letter glyphs, all 16 mandatory sentence-initial typed resonance markers, traditional base-six numbers, and the original canonical plea sentence.
- No change to the 2.0 noun case or verb suffix order.

## Additions

- **2,223 new candidate lexical senses**, curated concept-by-concept across 18 specialized fields; 50 overlap specifications were skipped rather than counted twice.
- **40 proposed grammar words** for event phase, temporal relations, focus, numerical bounds, epistemic provenance, confidence and interpersonal nuance.
- **4 productive derivations** that are documented but **not counted as dictionary headwords**.
- **504 new bilingual controlled examples** with compatible semantic roles or separately curated adjective predicates, bringing the corpus to **1,384** rows.
- Offline dictionary with exact edition and review-status filtering, 26-glyph visual converter and native PNG export.
- New checks for frozen 2.0 baselines, spelling inventory, morphology, reviewed statuses and corpus examples.

## Editorial limitations

Candidate forms use a deterministic orthographic scheme that preserves uniqueness and the permitted alphabet; their semantics are editorially specified but need speaker, phonotactic and sociolinguistic review. The 3.0 examples are educational templates, not an independently collected natural corpus. Full parity with modern natural languages requires authentic idioms, usage frequency, grammar testing with speakers, detailed cross-references, linguistic variety and native-script input infrastructure.

The project is distributed as a local source ZIP; this release does not assert any GitHub push or change the user's other Work thread.
