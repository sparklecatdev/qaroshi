# Qaroshi Reference release notes

## Standard 2.0 (major lexicon and grammar expansion)

- Preserved 853 distinct Standard Reference 1.0 dictionary entries, their spellings, classes, and English glosses.
- Added 24 fixed grammatical function words for counterfactual conditionals, optatives, collective and distributive expressions, confirmation tags, quotatives, embedded questions, discourse focus and customary knowledge.
- Added the documented perlative case `-nga` and four lexical derivations (`-wë`, `-këlë`, `-rëma`, `-sharo`).
- Added 5,942 candidate lexical senses across contemporary life and specialist domains. Of these, 234 are transparent two-part compounds. Candidate status signals unreviewed natural usage, not missing English glosses.
- Expanded corpus from 190 to 880 bilingual sentences: 660 controlled grammatical paradigms and 30 advanced samples.
- Added 35-section grammar reference, terminology and translation guidance, word indexes and domain counts.
- Bundled original 26 native glyph assets and a self-contained offline HTML dictionary with script conversion and local PNG export.
- Added CLI lookup, conservative sentence checks, native-script PNG rendering, morphological formatting, and automated regression tests.
- Added immutable lexical-spelling lockfile, domain-prefix registry and repository contribution guidelines.

**Compatibility:** existing 1.0 Romanization, the 16 obligatory resonance markers and established core sentences are unchanged. Future edits require review to preserve canonical meanings and spelling.

**Limitations:** 2.0 lexical candidates are not yet established through native-speaker usage, and example paradigms do not constitute a spontaneous attested corpus. There is no keyboard-installable native font, exhaustive semantic translator, or publicly pushed GitHub repository in this deliverable.
