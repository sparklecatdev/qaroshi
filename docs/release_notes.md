# Qaroshi Standard 5.0 · Release notes

## Dictionary and corpus

- 16,732 unique dictionary headwords: 11,878 preserved prior terms, 2,122 new standalone items, and 2,732 new transparent compounds.
- 3,077 bilingual sentences, all with a written resonance marker, IPA, stress guide and approachable sound-out.
- Expanded technical, practical, scientific, civic and Nardoragon-specific terminology across 35 new vocabulary domains.
- All 70 grammar chapters and 26 handwritten glyphs retained.

## Offline wiki redesign

- A more polished and restrained wiki visual style with a responsive sidebar and on-page table of contents.
- Homepage with subdued native-glyph artwork, clearer reference statistics and responsive reference cards.
- Faster dictionary lookups through pre-normalized search indices; accent-insensitive search for Romanized Qaroshi.
- Correct example links indexed by whole lexical tokens (avoids false positives from matching substrings).
- Dictionary compound components link directly to their constituent word pages.
- High-visibility English-style pronunciation, exact IPA and stress guides; collapsible letter-sound breakdowns for longer compounds.
- Improved responsive layouts, word wrapping, contrast and keyboard-focus states. No external assets or network dependencies.

## Integrity

Existing 4.3.1 lexical and corpus records are identical and retain their original IDs. Added terms are stable, uniquely spelled, non-inflectional canonical entries. The source code, sample corpus and original writing system are included with the release.

## Limitations

A large lexicon does not imply one-to-one parity with all natural-language idioms, dialects, usage frequencies or registers. A controlled translation example is not spontaneous-speech attestation. Phonetic pronunciation is rule-based, and English sound-outs are approximate.
