# Contribution protocol

Propose vocabulary with part of speech, semantic distinction, IPA, usage register, at least one sentence with mandatory opening resonance, and a description of how it differs from existing headwords. Propose grammar changes with positive and negative minimal pairs plus compatibility checks for noun cases, verb suffix order, quotation and scope. Add conversations with speaker roles, translation, consent/licensing and provenance. Adult terminology remains clearly marked and opt-in in random beginner exercises.

Submit human voice recordings only with explicit contributor consent, speaker/region information, stable lemma ID and distribution license. Generic browser speech synthesis is not speaker evidence. Keep original glyph artwork and the 16 resonance markers stable unless a carefully reviewed standardization change explicitly supersedes them. Record breaking changes in version control.
