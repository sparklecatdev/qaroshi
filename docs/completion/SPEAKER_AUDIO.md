# Speaker consent, audio and dialect evidence

**Collection status: zero authentic human Qaroshi recordings.** An empty 3,000-word target manifest does not constitute audio documentation.

Each volunteer recording should be logged against `data/editorial/human_audio_collection_manifest_3000.csv`, with the consenting speaker's chosen identity token, the word ID, intended register, locale, capture setup, file type, recording date, explicit distribution license, revocation request channel, and two independent reviewer decisions. Do not infer a speaker's age, gender, geographic origins, or dialect from an audio clip. Contributors may withhold any identifying information not necessary for a valid contribution.

Record one word or sentence per file with a spoken citation prompt and separate natural-speed attempt when feasible. Check clipping, noise, stress, segment inventory, speech rate, and whether the recorder can freely retract contributions. Treat dialect differences as hypotheses until independent speakers produce repeatable, consented evidence. Browser TTS and manually authored pronunciations remain approximations, not field recordings.

The workbench microphone helper records locally only. Some browsers will refuse microphone access from `file:` URLs; use an appropriate user-controlled secure context for actual recording. No data is uploaded by this release.
