# Standards publication and review policy

This is a **release candidate for developmental linguistic resources**, not an externally ratified Standard 10.0. The core dictionary, 26 glyphs, 16 mandatory resonance markers and baseline grammar are preserved. No draft idiom or gloss is silently promoted to canonical status by counting or software tests.

Recommended repository review process:

1. Publish a branch and opening PR rather than overwriting the main branch.
2. Add reproducible test output and checksums for every approved artifact.
3. Require a dictionary and grammar reviewer to approve every word-sense/idiom promotion; review with at least two independently translated minimal pairs when ambiguous.
4. Document cultural/fictional lore as editorial canon decisions, not as recorded history.
5. Publish speaker audio only with explicit consent and a release license.
6. Merge only independently reviewed standards changes, with migration guidance and regression checks.

The local ZIP can be shared as a development archive, but GitHub PR publication is **not** equivalent to an approved merged standard. An issue/PR exists for ongoing review; the entire ZIP has not been pushed automatically.
