# Qaroshi fluency expansion: controlled corpus and fieldwork boundary

A local Standards 8–10 development package now preserves the **30,000-entry lexicon**, 90 existing grammar chapters, 26 handwritten glyphs and 16 mandatory sentence-initial written resonance markers.

The current editorial additions are:
- **1,000 draft figurative entries**, produced from 25 metaphor families × 40 lexically grounded semantic anchors. These are *not* 1,000 independently conventionalized idioms.
- **5,000 draft sense cards**, linked to unchanged canonical headwords; contextual examples still require speaker review.
- **1,000 controlled 26-turn practice dialogues** (26,000 lines; **123,000 Qaroshi tokens**) that share a classroom dialogue arc; these are *not* 1,000 spontaneous conversations or a naturalistic literary corpus.
- A standalone, mobile-responsive **Qaroshi Fluency Lab**, with meaning practice, searchable sense cards and dialogue reader.
- A **3,000-word collection manifest** with **zero authentic recordings**; audio consent and dialect methods are documented.
- A testable local font builder (temporary PUA glyph mapping), experimental keyboard sources and conservative dictionary-based translation/checking.

All 24 original roadmap tasks are tracked in the sibling roadmap audit. **Human recording, speaker validation, independently authored literature, platform keyboard certification, fully general translation, and full source upload remain incomplete.**

The complete local ZIP bundle and HTML exist as conversation deliverables. This GitHub branch includes development documentation and issue workflows, but does **not** yet reproduce the entire local archive. Review [Issue #1](https://github.com/sparklecatdev/qaroshi/issues/1) before merging.

## Canonical preservation
An editorial inventory is not equivalent to a standardized linguistic category. Avoid changing source definitions automatically. Publish only independently reviewed additions.
