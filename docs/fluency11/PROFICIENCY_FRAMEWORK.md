# Qaroshi Q1–Q5: Self-study proficiency framework

This is an **internal study program**, not an accredited language examination and not a CEFR mapping. Automated multiple-choice performance cannot measure human pronunciation, conversation fluency, listening comprehension, spontaneous generation, or sociolinguistic judgement.

| Level | Focus | Target accuracy in an assessment |
|---|---|---:|
| **Q1: Foundation** | Core words, opening written resonances, original 26 letters | 75% |
| **Q2: Structure** | Noun roles, plural/case, basic argument structure | 78% |
| **Q3: Expression** | Past/future, aspect, negation, ability, permission, duty | 80% |
| **Q4: Reasoning** | Evidence, uncertainty, negation scope, translation contrasts | 82% |
| **Q5: Connected fluency** | Interpret situations and dialogue responses in context | 85% |

The included question bank has 472 items, produced from documented minimal contrasts, lexicon definitions, canonical glyph mappings, controlled translation templates and independently scripted new conversations. Every item has an explicit source category and an answer explanation. Assessments draw 20 questions from the relevant level. Progress is local and can be exported/imported as a JSON file. A passing result is called a **self-study milestone**, never formal certification.

## Assessment integrity

The native glyph exercise renders the image itself without displaying the romanized answer in the prompt. The quiz allows attempts at self-paced learning and shows the explanation only after a choice. Repeated attempts and viewing the source files make these unsuitable for external licensing or credentialing. For community proficiency claims, introduce independent, unseen oral/written tasks judged by trained humans and give confidence bounds.

## Pedagogical extension

The goal is communicative control, not simply recognition. Future evaluation should include original writing, spontaneous dialogue, paraphrase, ambiguity resolution, and auditory recognition. Pronunciation must be tested using **licensed human recordings**, not an English voice reading phonetic approximations.
