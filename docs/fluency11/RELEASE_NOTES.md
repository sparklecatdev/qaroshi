# Qaroshi 11.0 development release notes

**Status: editorial development release, not ratified language standard.**

## Implemented in this release

- More capable **Python bidirectional rule-based translator**, with semantic safeguards and exact lookup of all 4,383 controlled parallel reference examples.
- A separately generated, reproducible **1,572-pair productive translation table** covering known English/Qaroshi morphosyntactic templates. The pair count measures controlled templates, not idiomatic free-form translation.
- **49 independently scripted editorial conversations**, 294 turns and 1,263 source-language tokens. Contextual English paraphrases and literal grammar-engine interpretations are separately recorded.
- **472 question bank** across **five self-study levels**, with grammar, vocabulary, source-supported contrast and connected-reading questions.
- New **standalone offline learning app**, with reference lookup, a bounded translator, a sentence builder, dialogue reading, five proficiency levels, native glyph visualization, a reading library and local progress export/import.
- Original glyph art preserved. Contrast-enhanced *display copies* were added so the existing thin hand-drawn letters are readable against both light and dark interfaces.

## Compatibility

The 30,000-entry dictionary, 4,383 original examples, 90 grammar chapters, 16 obligatory written resonance registers and 26 native signs remain unchanged. The original Academy, Wiki, Studio, Fluency Lab and Completion Workbench are retained. The font-builder source remains available; no font binaries are distributed.

## Known limitations

This is not 1,000 additional spontaneous dialogues, a naturalistic 100,000-word corpus, an empirical dialect survey or a 3,000-speaker-word audio collection. Controlled translated sentence patterns cannot resolve every case of tense/aspect scope, idioms or subtle social meaning. The self-study milestone is not external language certification. All new materials are editorial and await language-community review.
