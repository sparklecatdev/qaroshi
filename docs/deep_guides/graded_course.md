# Qaroshi graded course · 16 detailed lessons

A complete route from first sentence to nuanced technical and literary translation. This is a **learning workbook**, not a proficiency certification or a claim about native-speaker frequency. Every modeled sentence is reproduced from the unified phrasebook, with stable IDs, phonetics and established English glosses.

## How to use each lesson

Read the goal, identify the grammar forms, and work through the comprehension table. Cover the English and translate from Qaroshi; cover Qaroshi and reconstruct from English. Repeat as spaced practice, and always check the opening resonance and speech-act ending. Each lesson includes a teacher key, so a self-learner can verify each whole sentence.

## Lesson 01 · Recognize a complete sentence

**Target skills:** Resonance, greetings, short assertions. **Source:** existing reference sentences S00001, S00002, S00003, S00004, S00005, S00006, S00007, S00008, S00011, S00012.

### Learning procedure

1. Read all ten examples aloud, using the IPA as the precise phoneme guide and capitals in the reading as a stress cue.
2. Mark the first word of each complete sentence; explain its register rather than simply calling it “tone.”
3. Underline subject and direct object where relevant. Parse hyphenated suffixes before translating.
4. For every verb, state whether it is unmarked, past, future, ongoing, habitual, able, permitted or obligatory.
5. Translate the full sentence into natural English; retain questions, requests, evidentials and participant roles.
