# Qaroshi learning library · unified reference 5.1

This learning library supplies step-by-step interpretation of the same established Qaroshi 5.0 grammar. The dictionary, native letters, phonetics, 16 registers and 70 canonical grammar chapters are unchanged. Lesson translations are sourced to the existing corpus IDs; the additional explanations are pedagogical commentary, not alterations to the rules.

## Suggested order

1. Read **Start here** and **Pronunciation laboratory**.
2. Work through **Guided course, lessons 1–8**.
3. Study **Resonance**, **Sentence anatomy**, **Nouns/cases**, and **Verb workshop**.
4. Work through **Guided course, lessons 9–16**, using **Questions**, **Clauses**, and **Evidence** as needed.
5. Read **Translation**, **Dictionary mastery**, **Technical writing** and **Native script** for polished production.
6. Test yourself with the **Practice workbook**, then use the **Sentence atlas** to repair persistent errors.
