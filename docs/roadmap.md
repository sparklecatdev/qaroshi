# Roadmap toward Contemporary-Language Parity

A reference with 6,819 unique lemmas supports much broader translation than a starter glossary, but modern language parity is multidimensional. A mature language needs semantic depth, corpus usage, flexible sentence constructions, sociolinguistic nuance, and script infrastructure.

## Current coverage

- **Basic grammar:** SOV syntax, noun roles, adjective positioning, verbal tense/aspect/modality, passive/causative/reflexive/reciprocal structures.
- **Complex syntax:** causal, purpose, temporal, conditional, counterfactual, concessive, quotation, relative, embedded question, information-structure focus, and polite wishes.
- **Social expression:** mandatory sentence-initial resonance, gender-neutral pronouns, inclusive/exclusive plurals, respect and consent language.
- **Lexical domains:** technology, communications, law, government, finance, computing, mathematics, physics, medicine, biological sciences, nature, household, food, clothing, arts, education, travel, psychology, philosophy, Nardoragon anatomy and flight culture.
- **Reference data:** lexicon CSV/JSON, English index, original art, offline search/converter, and 880 parallel/controlled example sentences.

## Next milestones (ordered by linguistic value)

1. **Review core frequency:** Build a 2,000–3,000-item frequency list from original, consented Qaroshi conversations. Identify most common senses, not just English dictionary frequency. Promote authentic common forms.
2. **Semantic disambiguation:** Link each lemma to explicit senses, synonyms, antonyms, metaphorical extensions, collocations, countability and verb argument frames.
3. **Idioms and discourse:** Collect natural dialogue, humor, irony, teasing, grief, formal meetings, literary writing, and culturally characteristic expressions. Record resonance choice for each independent sentence.
4. **Natural corpus:** Target at least 10,000 edited, genuinely translated sentences and longer narratives across multiple registers; annotate clause structure, morphology, and speaker intent. Controlled paradigms are useful but not a substitute for attestation.
5. **Phonological research:** Document stress exceptions, phonotactic alternations, fast-speech reductions, Nardoragon voice and resonance acoustics, and variation across speakers or regions.
6. **Better parser/grammar checker:** Move from token/suffix validation to typed morphological analysis, valency checking, clause parsing, quotation scope, negation scope, quantifier constraints and natural error suggestions.
7. **Script standardization:** Define reproducible stroke order, keyboard layout, bitmap/vector quality norms, reversible glyph-ID interchange and eventually native font technology. Do not invent Unicode codepoints.
8. **Bilingual dictionary depth:** Add example usages, reliable etymology, register constraints, word frequency and cross-references; prevent polysemous English terms from becoming accidental single-sense mappings.
9. **Specialist fields:** Expand scientific classification, civil/legal concepts, precise healthcare terms, banking, engineering, mathematics, and internet standards through expert review.
10. **Publishing and governance:** Set a verified license; document artwork provenance; establish versioned proposals and release notes; publish a contribution policy and accepted change-log on GitHub.

## Proposed measurable gates

| Gate | Criterion | Present status |
|---|---|---|
| Core compatibility | 853 original entries unchanged | Met in automated tests |
| Typed resonance | All 16 mandatory markers retained | Met in tests and corpus samples |
| Lexicon scale | At least 5,000 searchable entries | Met: 6,819; most new terms still candidate status |
| Example scale | At least 500 bilingual examples | Met: 880; only 190 from original reference |
| Spelling consistency | Every dictionary headword fits 26-glyph inventory | Met in automated checks |
| Natural corpus | 10,000 edited, attested sentences | Not yet met |
| Semantic/valency annotation | Detailed senses and argument patterns | Partial, needs systematic review |
| Fully native keyboard/font | Stable cross-platform text input | Not yet met |
| Community linguistic review | Proposals reviewed by fluent users | Not yet met |
| Public repository | Pushed, licensed and archived on GitHub | Not done in this package |

**Quality rule:** no milestone can be declared complete merely because a machine generated more headwords or morphologically predictable inflections. Verified usage, clear syntax and semantic robustness are required.
