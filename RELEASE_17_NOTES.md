# Qaroshi 17.0 release notes: making the language usable

## Changes

This release intentionally makes **zero changes to canonical grammar, glyphs, vocabulary or existing bilingual reference examples**. It is a practical teaching and reference application, not a newly ratified language revision.

The large v15.1 procedurally composed corpus suffers heavy repetition, and the v16.2 root-shortlist is still provisional. Rather than inventing more terms or repeating templates, 17.0 brings a smaller, traceable selection of existing source material to the foreground for everyday tasks.

The everyday communicator includes browsable and filterable phrases with pronunciations, coherent existing editorial dialogues and turn-by-turn translation reveals, restricted sentence composition, native-script viewing and e-accent input, 30,000-term reference search, an introductory root learning set, and 10 recap drills. Personal progress is stored in the browser.

## Honest numbers and provenance

- 656 exact Q-ID source phrases: 190 original phrasebook + 106 later living-speech teaching examples + 360 topical examples.
- 32 original editorial dialogue scenes, 192 turns, all reproduced from existing scripts.
- 10 five-phrase practical recall lessons, 120 source-derived root study cards.
- 390 structural SOV builder test fixtures, limited to the explicit predicate and argument tables in the source builder script.
- 16 retained written resonance markers, 26 retained native glyph artworks.
- 92 phrase-level review warnings carried forward from the existing v14 auditor (some records have multiple warnings). Eight foundational examples receive structural-review warnings and remain in the app unchanged.
- 0 independently attested natural speaker utterances, 0 recorded pronunciation audio, 0 formally approved replacement lexemes.

## Verification

Run the included test suites to reproduce the exact counts. Browser tests exercise real desktop and narrow/mobile viewports using Chromium and `set_content` because managed browser URL navigation may be restricted. These checks establish interface behavior, not independent linguistic naturalness.
